# Order Payment Module

Manage multiple payments for a single order in PrestaShop.

## Features

- View list of payments for each order.
- Add new payments manually.
- Associate documents (receipts, etc.) with payments.
- Track total paid and remaining balance.
- Visual badges in the order list indicating payment status.

## Installation

1. Upload the `orderpayment` folder to your `/modules` directory.
2. Install the module from the PrestaShop back office.

## Usage

- Go to an Order details page.
- Scroll down to the "Payments" section.
- Add, view, or delete payments as needed.
- In the Order List, look for the "Payment Status" column.
